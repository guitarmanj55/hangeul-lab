About the method

Hangeul was designed in 1443 to be learned in a day — each letter shape reflects the mouth or tongue position used to say it. This app leans on that: shape mnemonics for recognition, a block builder for how letters combine, then spaced repetition (a simplified SM-2 scheduler, the same family of algorithm behind Anki) so recall sticks instead of fading in a week.

Reading comes first by design — vocab drills always show Hangeul, never romanization, as the primary prompt. Speaking practice layers on once a word is recognisable on sight.
